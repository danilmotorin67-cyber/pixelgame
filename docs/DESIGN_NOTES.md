# DESIGN NOTES

Отклонения и решения сверх документа.

## Текущая веха

M0 каркас в каталоге `GameCLM`. Godot в среде не установлен — проект файловый, запускается после открытия в Godot 4.4+.

## Решения

1. Имя папки среды: `GameCLM` (запрос пользователя), внутри — структура из §33.2.
2. Автозагрузка аудио названа `AudioMgr`, не `Audio`, чтобы не конфликтовать с классом Godot `AudioServer`/`Audio`.
3. Стартовый баланс не менялся (±0%).
4. Временный арт M0: цветные прямоугольники + `.pxl` заготовка героя. Палитра saltlight48 соблюдена в билдере.
5. Приливы в Clock — полусуточная синусоида; точная таблица из tides.json подключается в M1.
6. CSV-локализация лежит как источник; `.translation` Godot генерирует редактор. Пока `Loc.t()` использует `tr()`.
7. Консоль `~` работает на мысе без отдельной сцены.
8. Системы M2–M9 имеют сериализацию и минимальное состояние, без пустых квестов-заглушек в смысле «сломано»: данные квестов P2 и Q1.1 уже в JSON.
